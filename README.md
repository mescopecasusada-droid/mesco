# MESCO — site

Arquivos prontos para o repositório.

## Estrutura
- `MESCO.dc.html` — página principal (abre direto no navegador)
- `support.js` — runtime necessário, não editar
- `image-slot.js` — componente usado pela página, não editar
- `assets/` — imagens (hero, peças, logo)

## Deploy
Sobe a pasta como está (raiz do repo ou subpasta) e serve `MESCO.dc.html` como index. Se for renomear para `index.html`, mantém os caminhos relativos (`./support.js`, `./image-slot.js`, `./assets/...`) intactos.
